# Main experiment results

Files in this directory are generated by `experiment/scripts/RunCEJavaPrompt.py` and `experiment/scripts/AnalyzeCEJavaPrompt.py`.

```text
results/main/
├─ ExperimentConfig.json
├─ GenerateResultJava/
│  ├─ Run1.jsonl
│  ├─ Run2.jsonl
│  └─ Run3.jsonl
├─ EvaluateResultJava/
│  ├─ Run1.jsonl
│  ├─ Run2.jsonl
│  └─ Run3.jsonl
└─ AnalysisJava/
   ├─ PassAtKJava.csv
   ├─ ConditionResultJava.csv
   ├─ DependencyResultJava.csv
   ├─ DependencyConditionJava.csv
   └─ SummaryJava.json
```

Each Run file corresponds to the same 1,816 jobs in `experiment/data/CEJavaPromptJobs.jsonl`. The three independent evaluation results are joined by `job_id` to calculate Pass@1 and Pass@3.
